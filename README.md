# Dashboards

Pranera ERP Dashboards — Sales, Purchase, Work Order and more.

A Frappe app providing analytical dashboards for Pranera ERP with PWA support.

## Features
- Sales Dashboard (Sales Invoices & Sales Orders)
- Purchase Dashboard (coming soon)
- Work Order Dashboard (coming soon)
- PWA support — installable on mobile devices

## Installation

```bash
bench get-app https://github.com/aravindsprint/dashboards
bench --site your-site install-app dashboards
```
